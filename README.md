# Monopoly - เกมเศรษฐี (Line Let's Get Rich Style) 🎲👑

โปรเจกต์เว็บเกมเศรษฐีจำลองสไตล์ "Line เกมเศรษฐี" (Let's Get Rich) สำหรับการเรียนรู้การเขียนเว็บแบบ Full-stack (Front-end และ Back-end) สำหรับผู้เริ่มต้น โดยไม่ใช้ไลบรารีภายนอก (Zero External Dependencies)

---

## 🌟 จุดเด่นและฟีเจอร์ของระบบ
1. **กระดาน 2.5D Isometric (สี่เหลี่ยมข้าวหลามตัด)**:
   - ใช้ CSS3 3D Transforms (`rotateX` และ `rotateZ`) ให้มุมมองเฉียง 45 องศา คล้ายเกมเศรษฐีของจริง
   - โทนสี Sci-Fi Neon / ค่ำคืนแคมป์ไฟ ตามภาพตัวอย่าง
2. **โปรไฟล์ผู้เล่น 4 คน 4 มุมจอ**:
   - ซ้ายบน (Top-Left): ผู้เล่นคนที่ 1
   - ขวาบน (Top-Right): ผู้เล่นคนที่ 2
   - ล่างซ้าย (Bottom-Left): ผู้เล่นคนที่ 3
   - ล่างขวา (Bottom-Right): ผู้เล่นคนที่ 4
   - แสดงชื่อ Username, อันดับที่เท่าไหร่ในตาราง (Rank 1-4), เงินสด (Cash), และทรัพย์สินรวม (Net Worth)
3. **ระบบการเล่น (Line Let's Get Rich Rules)**:
   - ซื้อที่ดินและสร้างสิ่งปลูกสร้าง 3 ระดับ (บ้านพัก, ตึก, โรงแรม)
   - สร้าง "แลนด์มาร์ก" (Landmark) เพื่อป้องกันการถูกเทคโอเวอร์
   - การจ่ายค่าผ่านทาง และการซื้อต่อ/เทคโอเวอร์ (Takeover) 2 เท่า
   - ทอยลูกเต๋าคู่ (Double Dice) ได้เดินต่อ / ดับเบิ้ล 3 ครั้งติดเกาะร้าง
   - ช่องพิเศษ 4 มุม: จุดเริ่มต้น START, เกาะร้าง, จัดงานเทศกาล (x2), สถานีอวกาศ (บินรอบโลก)
   - การ์ดดวง (Chance Cards) สุ่มผลลัพธ์
   - เงื่อนไขชนะเกม: ทำให้คู่แข่งล้มละลาย (Bankruptcy), Line Monopoly (ครองทั้งแถว), Triple Monopoly (ครอง 3 สี)
4. **ระบบเสียงในตัว (Pure Web Audio API)**:
   - สังเคราะห์เสียงเหรียญ, เสียงลูกเต๋า, เสียงสร้างตึก, และเพลงชัยชนะ โดยไม่ต้องดาวน์โหลดไฟล์เสียงภายนอก
5. **Back-end Node.js ไร้แพ็กเกจเสริม (Zero Dependencies)**:
   - ใช้โมดูลมาตรฐาน `node:http` และ `node:crypto`
   - ระบบ Native WebSocket Server (RFC 6455) รองรับการสร้างห้องด้วยรหัส 4 หลัก และเชื่อมต่อแบบ Real-time

```
MonopolyGame/

├── Assets/
│   └── Images/                   # ไฟล์รูปภาพ (favicon, icons)
├── src/
│   ├── css/

│   └── js/
│       ├── config.js             # ข้อมูลช่องทั้ง 32 ช่อง, กลุ่มสี, ราคา, การ์ดดวง
│       ├── audio.js              # ตัวสังเคราะห์เสียง Web Audio API
│       ├── player.js             # คลาสจัดการข้อมูลผู้เล่นและการเงิน
│       ├── board.js              # ตัวเรนเดอร์กระดานและอนิเมชันเดินหมาก
│       ├── dice.js               # ระบบทอยลูกเต๋า 2 ลูก และตรวจเต๋าคู่
│       ├── bot.js                # AI ปัญญาประดิษฐ์สำหรับเล่นคนเดียว
│       ├── network.js            # ตัวเชื่อมต่อ WebSocket ฝั่ง Client
│       ├── game.js               # ตัวควบคุมเกมหลักและกฎกติกา
│       └── app.js                # จุดเริ่มต้น (Entry Point) ของหน้าเว็บ

    ├── server.js                 # เซิร์ฟเวอร์ HTTP และ Native WebSocket
    └── roomManager.js            # จัดการห้องเล่น (Room Code) และ Sync ข้อมูล
```

## 🚀 วิธีการเปิดใช้งานเกม (How to Run)

### วิธีที่ 1: เล่นผ่านเซิร์ฟเวอร์ Back-end Node.js (แนะนำ)
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:

```bash
node backend/server.js
```

จากนั้นเปิดเว็บเบราว์เซอร์ไปที่:
👉 **http://localhost:3000**

คุณสามารถ:
- กด **"เล่นคนเดียว (แข่งกับบอท 3 คน)"** เพื่อเล่นทันที
- หรือกด **"สร้างห้องออนไลน์"** เพื่อสร้างห้องแล้วนำรหัสห้องให้เพื่อนในเครือข่ายเข้ามาร่วมเล่นได้

---

### วิธีที่ 2: เปิดเล่นผ่านไฟล์ HTML โดยตรง (โหมดออฟไลน์)
สามารถเปิดไฟล์ `MonopolyGame/index.html` ด้วยเว็บเซิร์ฟเวอร์จำลอง (เช่น Live Server บน VS Code) ได้ทันที ระบบจะสลับเข้าสู่โหมดเล่นคนเดียวกับ Bot AI ให้อัตโนมัติ
